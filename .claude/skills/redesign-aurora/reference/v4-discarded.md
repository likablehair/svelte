# Comportamenti v4 scartati o da rivedere

| Componente v4 | Comportamento | Esito |
|---|---|---|
| SimpleTextField | `range`: 7 prop in più, attributi ed eventi duplicati sui due input, secondo input senza nome accessibile, valori ammucchiati al centro, nessuna validazione | scartato: due campi affiancati |
| SimpleTextField | icona del calendario nativa trasparente ma cliccabile | scartato: icona visibile |
| SimpleTextField | `outline: none` senza focus visibile | corretto (P7) |
| Icon | `<span role="button">` sempre, anche se non cliccabile; Invio sì, Spazio no | scartato: Icon solo immagine, cliccabile = Button |
| Button | `disabled` non passato al `<button>` nativo | corretto |
| Button | `appendSnippet` in posizione assoluta sul bordo destro, sopra il testo | rivisto (2026-10-08): torna `appendSnippet` + `appendIcon`, in coda al testo e nel flusso, spinto al bordo destro se il bottone è più largo del contenuto; non copre più il testo |
| DatePickerTextField | id fissi `from` e `to`; parsing su `keydown` + `setTimeout(30)` (incolla e autofill ignorati, `oninput` anche per Tab e frecce); `activatorSnippet` che non può collegare la maschera; clic su mese/anno che svuota il testo lasciando la data; non si chiude dopo la scelta; ore del pattern perse; nessuna prop `locale` (sempre italiano); `minYearInRange` 1970 troppo stretto | scartato (ex P45) |
| Calendar | `isLeapYear` = `year % 4` (febbraio 2100 sbagliato); in inglese i giorni del mese prima sfasati di uno; `today` calcolato al mount; celle `div role=presentation` senza tastiera né ARIA; intervallo di un giorno impossibile; raggi di inizio/fine intervallo asimmetrici; header "L M M G V S D" ambiguo; `disabled` senza aspetto | scartato: `Intl`, griglia APG |
| DatePicker, YearSelector | clic sull'anno già scelto = `selectedYear` undefined → crash `visibleYear.toString()`; bottoni senza `type="button"` (submit nei form); `onclick` + `onkeypress` che con Invio scattano due volte; `selectedMonth`/`selectedYear` non legati alla data; `disabled` solo sulla griglia; `scrollAtCenter` che va in crash con un anno fuori lista | scartato |
| MonthSelector | `selectorSnippet` senza handler (uno snippet non può scegliere); refuso `"trasparent"` | scartato: `itemSnippet` del solo contenuto |
| YearPickerTextField | `openingId` fisso condiviso; su mobile ignora min/max; testo non svuotato quando l'anno torna `undefined` | scartato |
| Dialog, Drawer | Esc chiude tutti gli overlay aperti e ignora `persistent`/`closeOnClickOutside`; uscita animata dietro la pagina (`z-index !important`); contenuto chiuso montato, focusabile e letto; niente ARIA, focus trap né ritorno del focus; blocco scroll che resta se si smonta da aperto (Drawer: nessun blocco); style prop perse col teleport; z-index mai azzerati | scartato: `<dialog>` modale, smontato da chiuso |
| Drawer | `overlay` forzata a `true` a ogni apertura; `teleportedUid` pubblico che disattiva il teleport; `items` + Navigator di ripiego mai usati | scartato |
| Chip | `role="button"` sempre (anche senza `onclick`), non focusabile senza `buttonTabIndex`, click sintetico su Invio/Spazio, bottone X annidato nel "bottone" | scartato: `<button>` solo se cliccabile, X fratello |
| Checkbox | 2 listener globali su window per ogni checkbox per `shiftKeyPressed`; `outline: none` | scartato: `event.shiftKey` nativo, focus ring |
| Switch | input `display:none`: niente tastiera né focus; `--switch-label-width` usata da HeadersDrawer ma inesistente | scartato: input focusabile `role="switch"`, `label` vera |
| Menu | posizione calcolata risalendo i genitori (casi fixed/sticky/`display:flex`), listener di scroll sui genitori mai rimossi, dipendenza dallo store della sidebar, z-index in gara, `openingId` con click sintetici su div nascosti, `refreshPosition` booleano-comando, flip e viewport spenti di default, niente Esc né focus | scartato: top layer + posizione sullo schermo |
| Select | `placeholder` passato al `<select>` (nessun effetto); icone dentro `<option>` mai visibili; `optionAttributes` uguali per tutte le opzioni; `outline: none`; refuso `--selecr-active-border-color` | scartato: placeholder come opzione nascosta, icone con `base-select`, focus ring |
| Dropdown | X cliccabile annidata nel bottone; "N Selezionati" in italiano anche con `lang='en'`; `searchText` e `maxVisibleChips` senza effetto; click sul bottone aperto che non chiude; Backspace che toglie valori da un bottone; campo di ricerca nel drawer mobile | scartato |
| AsyncAutocomplete | `searching` prop morta (scritta, mai letta né bindable); nessun annullamento (vince l'ultima risposta che arriva); nessun `.catch`; risultati vecchi mostrati non filtrati sotto soglia; `search` booleano-comando che usa il testo col debounce; `closeOnSelect` `false` di default; esempio delle docs che va in crash dopo 20 ricerche | scartato: `signal`, `searching` bindable, riga d'errore, `search()` |
| CountriesAutocomplete | callback dentro `autocompleteProps` persi in silenzio; `onkeydown` tipizzato come `onblur`; lista ordinata per codice e solo in inglese stile ISO; ricerca che non trova codici né nomi senza accenti; `--countries-autocomplete-flag-icon-size` usata nelle docs ma inesistente | scartato: prop dirette, `Intl.DisplayNames`, ricerca su nome e codice |
| RadioButton | `checked` `$bindable` ma passato one-way (il binding non si aggiorna mai); `<label for={id}>` con `id` undefined di default (il click sul testo non seleziona); eventi tipizzati `() => void`; `outline: none` | scartato: `bind:group`, radice `<label>`, focus ring |
| Textarea | `id = createId()` casuale (mismatch SSR); nessun focus visibile (`--textarea-default-focus-box-shadow` e `-border` non definite); margin della label su elemento inline; `height: 100%` di default | scartato: `$props.id()`, base `--global-input-*` |
| LinkButton | `disabled` blocca solo le callback ma il link naviga; nessun attributo nativo inoltrato; `display: flex` e `align-content` (icone storte); `onkeypress` | scartato: `<a>` senza `href` + `aria-disabled`, attributi nativi |
| ActivableButton | niente `aria-pressed`; `buttonProps` al posto delle prop dirette; 16 variabili con nomi `-deactive-`/`-active-active-` | scartato |
| ConfirmOrCancelButtons | Annulla è un `<button>` nudo e `cancelDisable` non lo disabilita; `marginTop` di 20px di default; breakpoint 769px sul viewport | scartato: Button `text`, niente margine, container query |
| Autocomplete | `openingId` ignorato (id fisso condiviso: aprirne uno chiude tutti), `{#key searchText}` che rimonta il menu a ogni tasto, Backspace che non toglie il valore se non si è scritto prima, crash con Invio su lista vuota, Invio che invia il form, frecce che spostano il cursore, `keypress` del contenitore che riapre il menu dopo 50 ms, righe focusabili che rubano il focus, `==`/`===` mischiati (duplicati), `searchText` iniziale cancellato, `menuSnippet` senza parametri, `itemSnippet` che perde il click, `disabled` solo estetico, hint dentro l'area cliccabile, niente ARIA né focus visibile | scartato: combobox ARIA, focus nell'input |
